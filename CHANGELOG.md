# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-15

### Added

* Personal expense tracking system
* Budget management and monitoring
* Profile-based expense organization
* Expense history and transaction records
* Financial dashboard with spending insights
* Recovery and contribution tracking
* QR code scanning for payment information
* UPI-assisted payment workflow
* Custom UPI application detection and launcher
* Pending payment recovery system
* Payment confirmation dialog workflow
* Accurate expense timestamp preservation using payment initiation time
* Confirmation audit timestamp (`confirmedAt`)
* Local data persistence using Hive
* Android device support
* Modern app branding and logo

### Improved

* Reliable detection of installed UPI applications
* Enhanced payment recovery workflow
* Improved transaction timeline accuracy
* Better handling of payment confirmation events

### Fixed

* UPI application discovery issues caused by Android package visibility restrictions
* Missing detection of major UPI applications such as PhonePe and Google Pay
* Payment timestamp consistency between initiation and confirmation stages
